# Hotel Reservation System

A simple Java-based Hotel Reservation System that allows users to manage hotel room bookings through a console menu.

## Features

* View available and booked rooms
* Book a room
* Cancel a booking
* View booking details
* Check-in and check-out
* Calculate room charges based on the number of days
* Save booking details using file handling

## Technologies Used

* Java
* File Handling
* Scanner
* Arrays

## How to Run

1. Install Java JDK.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal and run:

```bash
javac HotelReservationSystem.java
java HotelReservationSystem
```
